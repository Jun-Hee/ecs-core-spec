🔥 1차 배포본 v1.5 대비 9개 영역 정정 (요약)

상세는 HTML의 "⚠ 1차 배포본 v1.5 대비 변경점" 섹션 참조.

# 영역 1차 (v1.5) 2차 (현재)
1 Scheduler 우선순위 priority_score 산식 + Redis ZSET craneId별 + orderseq ASC (산식 폐기)
2 식별자 Cmd_Id = ECS 생성 UUID commandId = containerWiRef, taskNo = ULID (신규)
3 STS 동시 처리 Main+Portal 트롤리, 장비당 1 active 더블트롤리: Main 1 + Second 1 동시 active
4 Direction H/L/N 정의만 N → L 디폴트 변환, FRONT/REAR reject
5 Error Code ECS-VAL-001 등 다수 내부 코드 1001/2001/3001 + Batch partial success
6 ETA/ETW 계산 Dispatcher M1 내부 산식 Core 단일 + FMS 신규 IF 2종
7 AGV Swap 없음 신규 시나리오 + ledger
8 OCR 컨테이너 변경 즉시 작업 중단 OCR Exchange 패턴 + ledger
9 POW (Point of Work) DS/LD만 사용 QC/YC 단계별 routing + 상태 전이

추가 신규: BizFlow 5종 (J02/AT-JS001 Reject, S03-ARPT 매칭, AGV Swap, OCR Exchange) + 신규 IF (FMS position·ETW, taskNo Notify, Extension REST 5종, Kafka topic 세분화) + Batch Response 표준
